# 🤝 Contributing to SureShift

Thank you for your interest in contributing to SureShift!

We welcome developers who want to improve the project, fix bugs, add features, and improve documentation.

## 🚀 Getting Started

1. Fork the repository.
2. Clone your fork:

   ```bash
   git clone https://github.com/Kunalgome26/sureshift.git
   ```

3. Navigate to the project:

   ```bash
   cd sureshift
   ```

4. Install dependencies:

   ```bash
   npm install
   ```

5. Start the development server:

   ```bash
   npm run dev
   ```

## 🌱 Making Contributions

1. Create a new branch:

   ```bash
   git checkout -b feature/your-feature
   ```

2. Make your changes.
3. Test your changes locally.
4. Commit your work:

   ```bash
   git add .
   git commit -m "Add: describe your changes"
   ```

5. Push your branch:

   ```bash
   git push origin feature/your-feature
   ```

6. Open a Pull Request on GitHub.

## 🐛 Reporting Bugs

When reporting a bug, please include:

- A clear description of the issue.
- Steps to reproduce it.
- Expected behaviour.
- Actual behaviour.
- Screenshots, if applicable.

## 💡 Suggesting Features

We welcome ideas that improve the customer experience, transportation management, security, and overall functionality.

Please open a GitHub Issue to discuss your proposed feature before implementing major changes.

## 📋 Contribution Guidelines

- Write clean and readable code.
- Follow the existing project structure.
- Avoid committing API keys or sensitive information.
- Test your changes before submitting a pull request.
- Keep pull requests focused on one improvement.
- Be respectful and constructive.

## ❤️ Thank You

Every contribution helps make SureShift better.

Happy coding!
